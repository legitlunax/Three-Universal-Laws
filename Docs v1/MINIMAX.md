# MiniMax coding agent project entry

Read [STATE.md](STATE.md) first, then [AGENTS.md](AGENTS.md), before project work.
These are the canonical continuation state and project instructions; do not keep
a competing progress summary here.

MiniMax models (MiniMax-M3.1-Flash-Preview, MiniMax-M3, MiniMax-M2.7) can drive
the same workflow as any other coding agent. There is no automatic model or
reasoning-effort router, so the model and effort for each task are chosen
explicitly.

For setup, the model/effort selection table and the resume prompt, see
[docs/MINIMAX.md](docs/MINIMAX.md).
