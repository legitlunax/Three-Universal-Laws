# Singularity API

The canonical [Singularity API specification](docs/api/SINGULARITY.md) now
lives in `docs/api/`. A Singularity handler performs one declared operation
through Order with explicit dependencies and a restricted execution context.

See the [website implementation profile](docs/api/WEBSITE_INTEGRATION.md)
for current runtime limits. [STATE.md](STATE.md) is the implementation checkpoint.
